## 1. Хранительницы музея: Муся и Кети

Проект посвящён двум кошкам, ставшим символами бесконечной гармонии цифрового пространства:

- **Муся (Musya) — Хранительница Пространства**:
  Плюшевая серебристая кошка с мудрым, внимательным взглядом. Олицетворяет бесконечность и незыблемость пространственных координат.
- **Кети (Keti) — Хранительница Симметрии и Времени**:
  Изящная зеленоглазая кошка с хвостом-спиралью. Олицетворяет идеальную биективность и обратимость математических преобразований.

Оригинальные фотографии Муси и Кети интегрированы в дизайн музея:
1. **Геральдический баннер вверху сайта**: портретные медальоны с золотыми рантами, пульсирующей подсветкой и лапками-печатями.
2. **Интерактивная материализация**: нажатие на медальоны или кнопки «🐾 Портрет Муси» / «🐾 Портрет Кети» мгновенно загружает их канонические Babel-координаты, материализуя точные портреты кошек на холсте через обратную перестановку.
3. **Музейная табличка**: содержит официальную печать кураторов архива с миниатюрами Муси и Кети.

## 2. Математическая архитектура: Bijective Pseudorandom Permutation (PRP)

В отличие от тривиального кодирования байт в Base64, в проекте реализована **обратимая детерминированная псевдослучайная перестановка (PRP)** на базе 4-раундовой сети Фейстеля (Feistel-SPN block cipher):

$$\text{Координата (Address)} \xrightarrow{\quad \Pi_K \quad} \text{Экспонат (Image Pixels)}$$
$$\text{Экспонат (Image Pixels)} \xrightarrow{\quad \Pi_K^{-1} \quad} \text{Координата (Address)}$$

### Ключевые математические свойства:
1. **Строгая биекция (1-to-1 bijection):**
   Каждый допустимый адрес соответствует ровно одному возможному изображению, и каждое возможное изображение имеет ровно один математический адрес.
2. **Лавинный эффект (Avalanche Effect ~50%):**
   При изменении адреса всего на $1$ бит (например, при переходе к соседнему экспонату $A \to A + 1$) в восстановленном изображении меняется порядка **50% всех бит** (более 99% пикселей). Соседние экспонаты визуально абсолютно непохожи, что передаёт ощущение настоящего блуждания по бесконечным залам Вавилона.
3. **Абсолютная обратимость:**
   Алгоритм не использует одностороннее хеширование (SHA-256, MD5) и не сжимает данные с потерями. Любая фотография после нормализации переводится в массив пикселей, к которому применяется обратная перестановка $\Pi_K^{-1}$, вычисляющая её вечный адрес в каталоге.
4. **Неизменный ключ перестановки:**
   Все раундовые константы детерминированы и получены из шестнадцатеричных цифр числа $\pi$ (nothing-up-my-sleeve numbers), гарантируя 100% совпадение между реализациями на Python и JavaScript.

## 3. Два разрешения и форматы адресов

| Параметр | 32×32 (Standard) | 64×64 (Enhanced) |
|---|---:|---:|
| **Разрешение** | $32 \times 32$ | $64 \times 64$ |
| **Количество пикселей** | $1\,024$ | $4\,096$ |
| **Каналы** | RGBA (8 бит на канал) | RGBA (8 бит на канал) |
| **Байтов** | $4\,096$ байт | $16\,384$ байт |
| **Бит** | $32\,768$ бит | $131\,072$ бит |
| **Префикс адреса** | `b32_` | `b64_` |
| **Длина Base64URL** | **$5\,466$** символов (с префиксом) | **$21\,850$** символов (с префиксом) |
| **Пространство состояний** | $2^{32768} \approx 1.415 \times 10^{9864}$ | $2^{131072} \approx 1.157 \times 10^{39457}$ |

### Полная обратная совместимость:
- Новые адреса имеют префиксы `b32_...` и `b64_...`.
- Старые «прямые» Base64 ID (5 462 или 21 846 символов) либо с префиксами `32_`/`64_` декодируются напрямую без ошибок.

## 4. Визуальный стиль цифрового музея

- **Атмосфера**: глубокий космический обсидиан (`#07060b`), бархатный аметист (`#160c2b`), мягкая сияющая лаванда (`#c084fc`) и теплое звездное золото (`#fbbf24`).
- **Рама шедевра**: тёмный скошенный багет из аметистового дерева с золотым рантом, светлое внутреннее паспарту и резкий пиксельный холст (`image-rendering: pixelated`).
- **Навигация**:
  - `← НАЗАД` / `ВПЕРЁД →` — соседние координаты ($A \pm 1$).
  - `🎲 СЛУЧАЙНЫЙ` — случайный прыжок в пространстве.
  - Шаги `-10` и `+10`.
  - Горячие клавиши: `Влево`, `Вправо`, `Пробел` / `R`.
  - Быстрый доступ: `🐾 Портрет Муси` и `🐾 Портрет Кети`.
- **Инструменты**:
  - `🔍 ПЕРЕЙТИ ПО ID`: мгновенная материализация по адресу.
  - `📷 НАЙТИ ФОТО`: локальный расчёт адреса любого загруженного фото без отправки на сервер.
  - `💾 СКАЧАТЬ HD`: экспорт резкого PNG $512 \times 512$.
  - `🔗 ПОДЕЛИТЬСЯ`: прямая ссылка `?id=...`.
- **Двуязычность (i18n)**: переключение между русским и английским языками `[RU | EN]` с автоопределением языка браузера.

## 6. Запуск и тестирование

### Вариант 1. Автономный статический запуск (GitHub Pages)
Запустите локальный статический сервер:
```powershell
python -m http.server 8000 -d docs
```
Откройте в браузере:
- Главная галерея: [http://localhost:8000/index.html](http://localhost:8000/index.html)
- Зал экспонатов: [http://localhost:8000/explore.html](http://localhost:8000/explore.html)
- Тестовый стенд в браузере: [http://localhost:8000/tests.html](http://localhost:8000/tests.html)

### Вариант 2. Запуск через Flask API
```powershell
python python/app.py
```
Сервер будет доступен по адресу [http://localhost:5000](http://localhost:5000).

### Прогон тестов:
```powershell
# Тестовый набор Python (11 тестов)
python python/tests.py

# Кросс-платформенная проверка эталонных векторов
python test_compatibility.py
```
